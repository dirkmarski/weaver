This file outlines key technology options available for use in the weaver project. Treat the absence of options as this is open for the team to decide, whilst adhering to the ADRs.

LLM options:
 - a local Ollama service is available and can be used for experimentation. Use models already installed, do not download new models or alter the setup. Do not change the state of the Ollama server.
 - a production grade LLM can be made available with a request.
