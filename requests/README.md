# Requests

Items that need a decision from outside the team. One file per item, `NNN-short-name.md`,
numbered in order.

Status: Open
Raised by: <agent role>, session <id>, <date>

# NNN Title

## Request
What is asked, and why. Written by the agent that raises it.

## Response
The answer from outside the team. Binding, like governance context.

## Follow-up
What the raising agent did with the Response.

Lifecycle: Open (raised) -> Answered (Response written) -> Closed (the curator, once the
raising agent has recorded its Follow-up).
