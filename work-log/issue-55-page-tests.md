- Findings
  - S1 should-fix (robustness) tests/page.test.js:44 the load-wait loop ends silently after 2 s. Proven: with `index.html` pointing at a missing script, all 10 tests ran 2.7 s each (27 s) and failed with unrelated "Cannot read properties of null (reading 'dispatchEvent')". Suggested: after the loop, `if (await page.eval('window.__stale || !window.Sudoku')) throw new Error('page did not load')`; also check the `errorText` of the `Page.navigate` result.
  - S2 should-fix tests/page.test.js:16 the `seededRng` regex has no match guard. Proven: a shape change (e.g. `function  seededRng(`) gives "TypeError: Cannot read properties of null (reading '0')" at module load, also with `WEAVER_NO_CHROME=1`, so the skip path fails too. Suggested: `const m = ...match(...); if (!m) throw new Error('page.test.js: cannot find seededRng in sudoku.js (expects a two-space indented function)');`, or skip the extraction when `found.skip`.
  - S3 should-fix tests/chrome.js:40 cleanup is registered on `process.on('exit')` only. A SIGINT or SIGTERM to the test process (Ctrl-C) skips exit handlers: Chrome (11 processes) and the `weaver-chrome-*` profile remain (reproduced with a private TMPDIR, both signals). README line "removed when the run ends, also after a failed test" is true for failed tests but not for Ctrl-C. Suggested: after the `process.on('exit', close)` line add `['SIGINT','SIGTERM'].forEach((s) => process.on(s, () => process.exit(1)));`. Note a signal to the `node --test` parent may not reach the child; I signalled the runner by pattern and the leak happened either way; the tester may confirm with a real terminal Ctrl-C.
  - N1 nit tests/chrome.js:48-71 no timeout on fetch, websocket or `send`; a Chrome that opens the port but never answers hangs the run until node's own limit. Acceptable for MVP.
  - N2 nit tests/page.test.js:138 `givenConflict` (`.given .conflict` part) cannot fail, because a given cell has no input; `.given.conflict` can (a td mutant that marks the given was caught). Keep or drop the descendant selector.
  - N3 nit tests/page.test.js:192 `marks.digit || marks.digits`: `hintMarks` returns `digits`; drop the `||` branch. Line 196/200 `html: undefined` noise in f: have `read()` not include `html` and let h read `document.body.innerHTML` itself (the `html` field is used only by h, not unused).
  - N4 nit tests/page.test.js:127-149 scenario c/d chooses the first empty cell, which is also the first input of its row; so a mutant that adds `conflict` to the first input of the row (M11 below) survives. Pick a clashing cell that is not the first input in its row (add `k`/`pos` condition in `clashing`), or accept.
